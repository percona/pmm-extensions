16"""Resolve the ATW-owned PROXY task that carries ATW's run-result recorder. 

17 

18ATW's recorder cannot be stamped on the task its snippets dispatch under today: 

19those resolve to the shared ``exec-artifact`` / ``exec-python-artifact`` rows, 

20which are ``protected=True`` and seeded inside ``app/tasks/``, and 

21``TaskExecuteRequest`` carries no per-execution recorder override. A 

22``backend=PROXY`` task names a root task in ``data["task"]`` and carries its own 

23``run_result_recorder``; ``TaskHistory`` binds to the *dispatched* task while 

24``get_root_task`` is consulted only to pick the executor, so the proxy's recorder 

25fires and execution still runs under the root. 

26 

27Every degradation here returns ``None``, meaning "dispatch under the root 

28unchanged". Correctness then falls back to the reconciliation sweep, which is 

29strictly better than refusing to dispatch or wrapping a task whose behaviour is 

30unknown. 

31 

32A proxy is a **materialized copy** of the root's behavioural policy — owner, 

33anonymization mask, output path, alert hooks — because those are resolved off the 

34dispatched task. That is why nothing here is memoized: a cache keyed on the root's 

35name would keep dispatching under a superseded policy for as long as it stayed warm, 

36and for the mask that means the wrong PII treatment. The root is read on every 

37resolution, and an ATW-owned proxy that no longer matches it is rewritten rather 

38than refused; a task at the proxy name that ATW does not own is never rewritten. 

39Resolution happens once per distinct root per batch, so the reads scale with the 

40interpreters a request touches, not with its items. 

41"""

77class _RootPolicy(BaseModel): 

78 """Read the behavioural fields a proxy must reproduce from the root it wraps. 

79 

80 Every field here is resolved off the **dispatched** task rather than the root: 

81 ``prepare_task_history`` reads ``anonymize_mask`` directly and derives the 

82 default mask from ``owner``; ``read_run_result`` reads ``output_files_path``; 

83 and the dispatch-failure alert reads ``alert_on_fail`` / ``alert_detail_builder``. 

84 Wrapping a task therefore substitutes the proxy's values for the root's, so the 

85 proxy has to carry the root's own. 

86 

87 Hardcoding them instead would be correct only for the seeded interpreter roots. 

88 ``SnippetInterpreterConfig.task`` is a plain overridable setting, so an operator 

89 may point ATW at a task with a different owner, mask or output path — and the 

90 substitution is silent: the wrong PII policy applies, or results are read from a 

91 path the executor never wrote to. 

92 

93 Every field is required and strictly typed for the same reason. Together they 

94 decide the run's PII and alert policy, so a key missing from the upstream payload 

95 or a value of the wrong shape must decline the wrap rather than fall back to a 

96 default that applies a different policy with nothing reporting it. 

97 

98 ``run_result_recorder`` is deliberately absent: carrying ATW's own is the entire 

99 reason the proxy exists. 

100 

101 :param owner: The root's owner, from which the default anonymization is derived. 

102 :param anonymize_mask: The root's explicit anonymization bitmask, if any. 

103 :param output_files_path: Where the root's executor writes its output files. 

104 :param alert_on_fail: Whether a failed run of the root raises an alert. 

105 :param alert_detail_builder: The root's alert-enrichment hook path, if any. 

106 """ 

107 

108 owner: NonEmptyStr 

109 anonymize_mask: StrictInt | None 

110 output_files_path: str | None 

111 alert_on_fail: StrictBool 

112 alert_detail_builder: str | None

115def _build_proxy_task_write(root_task_name: str, policy: _RootPolicy) -> TaskWrite: 

116 """Build the proxy task ATW creates for ``root_task_name``. 

117 

118 The payload is deliberately thin — ``data`` carries only ``task``, with no 

119 ``meta`` and no ``payload`` key — because ``prepare_task_history`` merges a 

120 proxy's own meta *over* the caller's and substitutes its own payload for the 

121 caller's, either of which would override what the run itself asked for. 

122 

123 Everything else behavioural is copied from the root, so wrapping a task changes 

124 where the recorder points and nothing else — see :class:`_RootPolicy`. 

125 

126 :param root_task_name: The interpreter task the proxy dispatches through. 

127 :param policy: The root's behavioural fields, copied onto the proxy. 

128 :return: The create payload for the proxy task. 

129 """ 

130 return TaskWrite( 

131 name=atw_proxy_task_name(root_task_name), 

132 backend=TaskBackendEnum.PROXY, 

133 data={"task": root_task_name}, 

134 run_result_recorder=RUN_RESULT_RECORDER, 

135 **policy.model_dump(), 

136 )

179def _is_atw_owned(task: Mapping[str, Any]) -> bool: 

180 """Check whether a task found at the proxy name is one ATW may rewrite. 

181 

182 The proxy prefix is not reserved, the tasks service's update route checks no 

183 ownership, and a ``PUT`` replaces a task wholesale — so treating a name collision 

184 as licence to re-sync would let ATW overwrite someone else's task, backend and 

185 data included. ATW's own ``run_result_recorder`` is the ownership marker: it is 

186 the one field only ATW sets, and carrying it is the reason the proxy exists. A 

187 task without it is left alone and the dispatch runs under the root unchanged. 

188 

189 :param task: The upstream task payload found at the proxy name. 

190 :return: ``True`` when the task carries ATW's recorder. 

191 """ 

192 return task.get("run_result_recorder") == RUN_RESULT_RECORDER

195async def _fetch_task(tasks_api: RemoteAPI, name: str) -> dict[str, Any] | None: 

196 """Fetch one task by name, mapping a genuine absence to ``None``. 

197 

198 Narrowed to :class:`HTTPNotFoundException` rather than ``HTTPException``: a 

199 non-JSON 404 from a proxy or gateway stays a bare ``HTTPException`` and must 

200 propagate, because treating an infrastructure failure as "the task does not 

201 exist" would have this module create a duplicate. 

202 

203 :param tasks_api: The authenticated Tasks API client. 

204 :param name: The task name to fetch. 

205 :return: The task payload, or ``None`` when no such task exists. 

206 :raises HTTPUnprocessableEntityException: If ``name`` is not a single plain URL 

207 path segment. 

208 :raises HTTPException: Propagated for any upstream error status other than a 

209 JSON ``404`` — including a non-JSON ``404``, which signals a proxy or 

210 gateway failure rather than a missing task. 

211 :raises OSError: Propagated from the Tasks API when the transport itself fails. 

212 """ 

213 try: 

214 return as_json_object(await tasks_api.get(task_path(name))) 

215 except HTTPNotFoundException: 

216 return None

219async def _create_proxy_task( 

220 tasks_api: RemoteAPI, task_write: TaskWrite 

221) -> dict[str, Any] | None: 

222 """Create the proxy task, resolving a concurrent creator's win by re-fetching. 

223 

224 Both 409 and 400 are treated as a race rather than an error: 

225 ``TaskManager.create``'s duplicate precheck answers 409 only when it *sees* the 

226 row, so a concurrent insert instead trips the commit branch and raises a 400. 

227 Handling only 409 would turn a live race into a failed dispatch. 

228 

229 :param tasks_api: The authenticated Tasks API client. 

230 :param task_write: The proxy payload built from the root's current policy. 

231 :return: The created or concurrently-created task, or ``None`` if it vanished. 

232 :raises HTTPException: Propagated for any upstream error status other than the 

233 ``409`` / ``400`` pair that a concurrent creator produces. 

234 :raises OSError: Propagated from the Tasks API when the transport itself fails. 

235 """ 

236 try: 

237 return as_json_object(await tasks_api.post("/", json=task_write.model_dump())) 

238 except (HTTPConflictException, HTTPBadRequestException): 

239 logger.info( 

240 "ATW proxy task %s was created concurrently; validating the winner.", 

241 task_write.name, 

242 ) 

243 return await _fetch_task(tasks_api, task_write.name)

246async def _sync_proxy_task( 

247 tasks_api: RemoteAPI, root_task_name: str, task_write: TaskWrite 

248) -> dict[str, Any]: 

249 """Rewrite an existing proxy so it matches the root's current behaviour. 

250 

251 ``PUT /{task_name}`` replaces the task wholesale, and the payload is rebuilt from 

252 the root, so this both repairs a proxy left over from an earlier interpreter 

253 configuration and picks up a policy edit on the root itself. It is only ever 

254 called for a task carrying ATW's recorder — see :func:`_is_atw_owned`. 

255 

256 :param tasks_api: The authenticated Tasks API client. 

257 :param root_task_name: The interpreter task the proxy dispatches through. 

258 :param task_write: The proxy payload built from the root's current policy. 

259 :return: The updated task. 

260 :raises HTTPUnprocessableEntityException: If the proxy name is not a single 

261 plain URL path segment. 

262 :raises HTTPException: Propagated from an upstream error status. 

263 :raises OSError: Propagated from the Tasks API when the transport itself fails. 

264 """ 

265 logger.info( 

266 "Re-syncing ATW proxy task %s to the current behaviour of %s.", 

267 task_write.name, 

268 root_task_name, 

269 ) 

270 return as_json_object( 

271 await tasks_api.put(task_path(task_write.name), json=task_write.model_dump()) 

272 )

275def _wrappable_policy( 

276 root_task_name: str, root: Mapping[str, Any] | None 

277) -> _RootPolicy | None: 

278 """Return the root's policy when ATW may wrap the root, else ``None``. 

279 

280 Each refusal dispatches under the root unchanged and leaves the outcome to the 

281 reconciliation sweep: a root that does not exist, one that is itself a PROXY, one 

282 that already declares its own recorder, and one whose policy fields cannot be 

283 read. 

284 

285 :param root_task_name: The interpreter task being resolved, for logging. 

286 :param root: The fetched root task payload, or ``None`` when it does not exist. 

287 :return: The root's validated policy, or ``None`` to dispatch unwrapped. 

288 """ 

289 if root is None: 

290 logger.warning( 

291 "Interpreter task %s does not exist upstream; dispatching unwrapped.", 

292 root_task_name, 

293 ) 

294 return None 

295 if root.get("backend") == TaskBackendEnum.PROXY.value: 

296 # get_root_task resolves exactly one hop, so a proxy-of-a-proxy still 

297 # reaches get_executor as PROXY and raises "Unsupported backend", 

298 # breaking every dispatch under this interpreter. 

299 logger.warning( 

300 "Interpreter task %s is itself a PROXY; dispatching unwrapped to " 

301 "avoid a two-hop chain.", 

302 root_task_name, 

303 ) 

304 return None 

305 if root.get("run_result_recorder"): 

306 # maybe_record_run resolves exactly one recorder with no chaining, so 

307 # wrapping would substitute ATW's for the root's and silently stop 

308 # whatever that one records. 

309 logger.warning( 

310 "Interpreter task %s already declares a run-result recorder (%r); " 

311 "dispatching unwrapped rather than displacing it, and letting the " 

312 "reconciliation sweep supply ATW's outcome.", 

313 root_task_name, 

314 root.get("run_result_recorder"), 

315 ) 

316 return None 

317 try: 

318 return _RootPolicy.model_validate(root) 

319 except ValidationError: 

320 logger.exception( 

321 "Interpreter task %s reported a policy ATW cannot read; dispatching " 

322 "unwrapped rather than copying a guessed policy onto a proxy.", 

323 root_task_name, 

324 ) 

325 return None

328async def _resolve_one(tasks_api: RemoteAPI, root_task_name: str) -> str | None: 

329 """Fetch, validate, re-sync or create ATW's proxy for one interpreter root. 

330 

331 The root is read on every resolution rather than cached. The proxy is a 

332 *materialized copy* of the root's behavioural policy, so any window in which the 

333 root is not read is a window in which a superseded policy keeps being applied — 

334 and for ``anonymize_mask`` that means the wrong PII treatment. Reading it is the 

335 only way to know, so it is read. 

336 

337 :param tasks_api: The authenticated Tasks API client. 

338 :param root_task_name: The interpreter task to dispatch through. 

339 :return: The proxy task name, or ``None`` to dispatch under the root unchanged. 

340 :raises HTTPException: Propagated from an upstream error status that is neither a 

341 genuine ``404`` nor the create race's ``409`` / ``400``. 

342 :raises OSError: Propagated from the Tasks API when the transport itself fails. 

343 """ 

344 policy = _wrappable_policy( 

345 root_task_name, await _fetch_task(tasks_api, root_task_name) 

346 ) 

347 if policy is None: 

348 return None 

349 try: 

350 task_write = _build_proxy_task_write(root_task_name, policy) 

351 except ValidationError: 

352 # The payload is assembled from an arbitrary configured root, so it can be 

353 # rejected for reasons this module does not enumerate — a root name within 

354 # the 255-character limit whose prefixed form is not, or any inherited field 

355 # the model refuses. Declining keeps "every degradation dispatches under the 

356 # root" true instead of surfacing a 500 from a dispatch that could proceed. 

357 logger.exception( 

358 "Could not build ATW's proxy task for %s; dispatching unwrapped.", 

359 root_task_name, 

360 ) 

361 return None 

362 proxy_name = task_write.name 

363 proxy = await _fetch_task(tasks_api, proxy_name) 

364 if proxy is None: 

365 proxy = await _create_proxy_task(tasks_api, task_write) 

366 elif not _is_expected_proxy(proxy, root_task_name, policy): 

367 if not _is_atw_owned(proxy): 

368 logger.error( 

369 "Task %s exists but does not carry ATW's run-result recorder, so it is " 

370 "not ATW's to rewrite (backend=%r, run_result_recorder=%r); dispatching " 

371 "unwrapped so the sweep supplies the outcome instead.", 

372 proxy_name, 

373 proxy.get("backend"), 

374 proxy.get("run_result_recorder"), 

375 ) 

376 return None 

377 # The proxy exists but no longer matches the root — an interpreter re-pointed 

378 # at a task with a different policy, or the root's own policy edited. Re-sync 

379 # rather than refuse: refusing would degrade this interpreter permanently, 

380 # since nothing else ever repairs the row. 

381 proxy = await _sync_proxy_task(tasks_api, root_task_name, task_write) 

382 if proxy is None or not _is_expected_proxy(proxy, root_task_name, policy): 

383 logger.error( 

384 "Task %s exists but is not the proxy ATW requires and could not be " 

385 "reconciled to it (backend=%r, data=%r, run_result_recorder=%r); " 

386 "dispatching unwrapped so the sweep supplies the outcome instead.", 

387 proxy_name, 

388 None if proxy is None else proxy.get("backend"), 

389 None if proxy is None else proxy.get("data"), 

390 None if proxy is None else proxy.get("run_result_recorder"), 

391 ) 

392 return None 

393 return proxy_name

396async def resolve_atw_proxy_tasks( 

397 root_task_names: Iterable[str], 

398) -> dict[str, str | None]: 

399 """Resolve the proxy to dispatch through for each distinct interpreter root. 

400 

401 Resolved once per root for a whole batch rather than once per item: the roots in 

402 a batch are the handful its snippets' interpreters name, so a twenty-item request 

403 costs the same upstream traffic as a one-item request. 

404 

405 Nothing is memoized across calls. The proxy copies the root's behavioural policy, 

406 so a cache keyed on the root's *name* would keep applying a superseded 

407 ``anonymize_mask`` for as long as it stayed warm; reading the root each time is 

408 what makes the policy live, and the reads are per request, not per run. 

409 

410 The client is built here and authenticates as the service principal, so creating 

411 or repairing a proxy does not depend on the caller's own task permissions and the 

412 function works identically from a worker. 

413 

414 :param root_task_names: The interpreter tasks the batch's snippets would dispatch 

415 under; duplicates are resolved once. 

416 :return: The proxy name per root, or ``None`` against a root to dispatch under it 

417 unchanged. 

418 :raises HTTPException: Propagated from an upstream error status that is neither a 

419 genuine ``404`` nor the create race's ``409`` / ``400``. Raising leaves the 

420 decision to the caller: the batch route degrades the whole batch to unwrapped 

421 dispatch rather than splitting one request across two policies. 

422 :raises OSError: Propagated from the Tasks API when the transport itself fails. 

423 """ 

424 client = await get_tasks_api() 

425 with client.auth(get_internal_token()) as tasks_api: 

426 return { 

427 root_task_name: await _resolve_one(tasks_api, root_task_name) 

428 for root_task_name in dict.fromkeys(root_task_names) 

429 }
