16"""Define shared route helpers for schema-driven plugin routers. 

17 

18The helpers in this module register a plugin's well-known routes with a 

19single call so plugins never re-implement the auth posture, response-model 

20wiring, or status-code conventions: 

21 

22- :func:`schema_endpoint` and :func:`capabilities_endpoint` register the 

23 ``GET /schema`` and ``GET /capabilities`` discovery routes. 

24- :func:`derive_crud_routes` builds a plugin router carrying the schema 

25 route plus the standard list / detail / create (and optional update / 

26 delete) CRUD routes, composing the shared framework task helpers for the 

27 handler bodies. 

28 

29Pagination convention: paginate anything backed by an unbounded resource and 

30return a :class:`~app.core.pagination.PaginatedResponse` envelope; a bare list 

31is acceptable only for compile-time-bounded enumerations. Hand-written proxy 

32list routes build the envelope with 

33:func:`~app.core.pagination.build_proxied_page`, which corrects the ``total`` 

34when rows are filtered in-process.

171def resolve_response_model( 

172 provider: Callable[..., BaseModel], 

173 *, 

174 helper: str, 

175 param: str, 

176) -> type[BaseModel]: 

177 """Return the ``BaseModel`` subclass declared as ``provider``'s return type. 

178 

179 Unwraps a :class:`functools.partial` to its underlying function first, since 

180 :func:`typing.get_type_hints` rejects a partial — binding a builder with 

181 ``partial(...)`` is an established plugin pattern and resolves the same return 

182 annotation as the wrapped function. Then uses :func:`typing.get_type_hints` so 

183 deferred-evaluation annotations (``from __future__ import annotations``) resolve 

184 to the real class rather than a string. Falls back to the function's 

185 ``__annotations__`` dict only when :func:`typing.get_type_hints` raises 

186 :class:`NameError` — i.e. a forward-ref that resolves against a module the 

187 caller hasn't imported. Other failures propagate unchanged. 

188 

189 :param provider: A callable annotated with its return type. The 

190 callable may declare arbitrary parameters (typically resolved by 

191 FastAPI's dependency injection via ``Depends(...)``), and may be a 

192 :class:`functools.partial` over such a callable. 

193 :param helper: The public helper name, used to frame error messages. 

194 :param param: The offending parameter name, used to frame error messages. 

195 :return: The class declared as the provider's return annotation. 

196 :raises TypeError: If the annotation is missing, isn't a class, or 

197 isn't a :class:`pydantic.BaseModel` subclass. 

198 """ 

199 while isinstance(provider, functools.partial): 

200 provider = provider.func 

201 try: 

202 hints = typing.get_type_hints(provider) 

203 except NameError: 

204 # Forward-ref under ``from __future__ import annotations`` that resolves 

205 # against a module the caller hasn't imported — fall back to the raw 

206 # string annotation so the downstream isclass/issubclass check produces 

207 # the expected TypeError instead of leaking ``NameError`` here. 

208 hints = getattr(provider, "__annotations__", {}) 

209 

210 annotation = hints.get("return") 

211 if annotation is None: 

212 raise TypeError( 

213 f"{helper}: {param} must declare a return type annotation that is " 

214 f"a pydantic.BaseModel subclass (e.g. `def {param}() -> MyModel: ...`)" 

215 ) 

216 if not inspect.isclass(annotation) or not issubclass(annotation, BaseModel): 

217 raise TypeError( 

218 f"{helper}: {param}'s return type annotation must be a " 

219 f"pydantic.BaseModel subclass; got {annotation!r}" 

220 ) 

221 return annotation

224def _reject_async_builders(**builders: Callable[..., BaseModel] | None) -> None: 

225 """Raise ``TypeError`` if any named builder is an ``async def`` callable. 

226 

227 :func:`derive_crud_routes`'s handlers invoke the response builders 

228 synchronously, so an ``async def`` builder would yield an un-awaited 

229 coroutine that ``response_model`` serialisation cannot handle. Reject it at 

230 registration — mirroring :func:`capabilities_endpoint`'s sync-only guard — 

231 rather than letting it surface as an opaque failure on the first request. 

232 

233 :param builders: Builder callables keyed by their parameter name; ``None`` 

234 entries (an omitted optional builder) are skipped. 

235 :raises TypeError: If any supplied builder is a coroutine function. 

236 """ 

237 for label, builder in builders.items(): 

238 if builder is not None and inspect.iscoroutinefunction(builder): 

239 raise TypeError( 

240 f"derive_crud_routes: {label} must be a sync callable; the " 

241 "derived handlers invoke it synchronously, so an async builder " 

242 "would yield an un-awaited coroutine that response_model " 

243 "serialisation cannot handle." 

244 )

247def _reject_contextless_builders( 

248 context_provider: Callable[[], Awaitable[Any]] | None, 

249 **builders: Callable[..., BaseModel] | None, 

250) -> None: 

251 """Raise ``TypeError`` if a context provider cannot bind into a named builder. 

252 

253 When a ``context_provider`` is set, :func:`_bind_context` binds its result as 

254 each active builder's ``context`` keyword argument; a builder declaring neither 

255 a ``context`` parameter nor ``**kwargs`` would raise an opaque ``TypeError`` on 

256 the first request. Reject it at registration instead — mirroring 

257 :func:`_reject_async_builders`. 

258 

259 :param context_provider: The configured context provider; ``None`` skips the 

260 whole check (no binding happens). 

261 :param builders: Builder callables keyed by their parameter name; ``None`` 

262 entries (an omitted optional builder) are skipped. 

263 :raises TypeError: If a supplied builder cannot accept a ``context`` keyword. 

264 """ 

265 if context_provider is None: 

266 return 

267 for label, builder in builders.items(): 

268 if builder is None: 

269 continue 

270 parameters = inspect.signature(builder).parameters.values() 

271 accepts_context = any( 

272 parameter.name == "context" 

273 or parameter.kind is inspect.Parameter.VAR_KEYWORD 

274 for parameter in parameters 

275 ) 

276 if not accepts_context: 

277 raise TypeError( 

278 f"derive_crud_routes: {label} must accept a 'context' keyword " 

279 "argument when context_provider is set; the provider's result is " 

280 "bound into the builder via functools.partial(context=...)." 

281 )

299def capabilities_endpoint( 

300 router: APIRouter, 

301 capabilities_provider: Callable[..., CapabilitiesT], 

302) -> None: 

303 """Register a ``GET /capabilities`` route returning ``capabilities_provider()``. 

304 

305 Mirrors :func:`schema_endpoint` for the per-deployment runtime 

306 capability surface: same auth posture (``IsApiAuthenticated`` 

307 redeclared at the route level), same duplicate-registration guard, 

308 same ``response_model_exclude_none=True`` posture. Inferring 

309 ``response_model`` from the provider's return annotation keeps the 

310 call site terse — plugins write a one-line registration adjacent to 

311 their ``schema_endpoint(...)`` call. 

312 

313 .. code-block:: python 

314 

315 from app.extensions.apps.framework.api import capabilities_endpoint 

316 from app.extensions.snippets.config import snippets_settings 

317 from app.extensions.snippets.models.responses import SnippetsCapabilitiesResponse 

318 

319 def _snippets_capabilities() -> SnippetsCapabilitiesResponse: 

320 return SnippetsCapabilitiesResponse( 

321 manual_sync_enabled=snippets_settings.ENABLE_MANUAL_SYNC, 

322 ) 

323 

324 capabilities_endpoint(router, capabilities_provider=_snippets_capabilities) 

325 

326 Semantics: 

327 

328 - The provider is invoked **per request**, never cached, so a 

329 deployment-config hot reload between two calls is reflected on the 

330 next response without a process restart. 

331 - ``IsApiAuthenticated`` only — there is no admin gate. Capability 

332 flags are public-to-authed-users by design; if a plugin needs to 

333 gate privileged flags, expose them on a separate route, not here. 

334 - The provider must be a function (or method) with a return-type 

335 annotation that resolves to a :class:`pydantic.BaseModel` subclass. 

336 Lambdas are rejected because their syntax provides no way to declare 

337 a return-type annotation. 

338 - The provider may declare arbitrary parameters; ``functools.wraps`` 

339 preserves the signature so FastAPI inspects it and resolves any 

340 ``Depends(...)`` defaults per request (settings, session, current 

341 user, etc.). A zero-arg provider remains the most common shape 

342 (settings attribute read), but the helper does not enforce it. 

343 - The provider should be cheap. DB or network calls do not belong 

344 behind a synchronous provider; add an async-provider variant when 

345 a plugin needs that. ``async def`` providers are rejected at 

346 registration to keep the contract sync-only for now. 

347 - The new endpoint is intentionally separate from 

348 :class:`~app.extensions.apps.framework.schema.AppSchema.capabilities`, 

349 which describes static UI feature flags (chaining, scheduling, 

350 alert_on_fail). The two surfaces are not unified: schema-side 

351 ``Capabilities`` is per-plugin compile-time posture, capability 

352 responses returned here are per-deployment runtime posture that 

353 may toggle without a redeploy. 

354 

355 :param router: The plugin's ``APIRouter``. 

356 :param capabilities_provider: A callable returning a 

357 :class:`pydantic.BaseModel` instance. The return-type annotation 

358 is used as the route's ``response_model``. The callable's 

359 parameters (if any) are passed through to FastAPI for dependency 

360 resolution. 

361 :raises TypeError: If ``capabilities_provider``'s return annotation 

362 is missing, is not a class, or is not a 

363 :class:`pydantic.BaseModel` subclass. Raised at registration 

364 time, not first request. 

365 :raises ValueError: If ``router`` already exposes a 

366 ``GET /capabilities`` route. 

367 """ 

368 if inspect.iscoroutinefunction(capabilities_provider): 

369 raise TypeError( 

370 "capabilities_endpoint: capabilities_provider must be a sync " 

371 "callable; async providers are out of scope (see SEP-1133). " 

372 "Calling an async function from the sync handler would return a " 

373 "coroutine object that response_model serialisation cannot handle." 

374 ) 

375 response_model = resolve_response_model( 

376 capabilities_provider, 

377 helper="capabilities_endpoint", 

378 param="capabilities_provider", 

379 ) 

380 

381 router_prefix = getattr(router, "prefix", "") or "" 

382 expected_path = f"{router_prefix}/capabilities" 

383 for existing in router.routes: 

384 existing_methods = set(getattr(existing, "methods", None) or ()) 

385 if ( 

386 getattr(existing, "path", None) == expected_path 

387 and "GET" in existing_methods 

388 ): 

389 raise ValueError( 

390 "capabilities_endpoint: router already has a GET /capabilities " 

391 "route; call this helper at most once per plugin router" 

392 ) 

393 

394 @functools.wraps(capabilities_provider) 

395 def get_capabilities(*args: object, **kwargs: object) -> BaseModel: 

396 return capabilities_provider(*args, **kwargs) 

397 

398 router.add_api_route( 

399 "/capabilities", 

400 get_capabilities, 

401 methods=["GET"], 

402 response_model=response_model, 

403 response_model_exclude_none=True, 

404 dependencies=[IsApiAuthenticated], 

405 )

498

501 so the probe result has somewhere to land); else auto-derive a create model

505

507 :param base_model: The list/detail model used as the auto-derive base.

517 create_response_builder,

531 base_model, name=_create_response_name(plugin_schema) 

532 ) 

533 return base_model

577 task_write: TaskWrite, 

578 *,

580 ) -> BaseModel: 

581 """Build the create response, optionally attaching a connectivity warning. 

582 

583 The name arrives in the request body, where nothing narrows it to one 

584 path segment, but every route that later addresses the task composes the 

585 name into an upstream path. Refusing it before the POST keeps a task that

1759) -> APIRouter: 

1760 """Build a plugin router carrying a script source's derived surface. 

1761 

1762 Register the script-centric surface a script-backed task app exposes, mirroring 

1763 the working ``snippets`` JSON API: owner-agnostic listing (``GET /``), per-script 

1764 form schema (``GET /snippet/schema``), execute delegation 

1765 (``POST /snippet/execute``, ``201``), execution history 

1766 (``GET /snippet/history``), and — only when ``source.static_schema`` is set — the 

1767 plugin-level ``GET /schema``. All routes carry ``IsApiAuthenticated``. 

1768 

1769 Per-script routes carry the script filename in a ``snippet_filename`` query 

1770 parameter under the ``/snippet/`` sub-prefix (never a path segment), so a greedy 

1771 detail route cannot shadow ``GET /`` or ``GET /schema``. The execute route 

1772 validates the request ``args`` against the script's dynamic execution model 

1773 (``422`` on failure), delegates meta assembly to ``source.build_execution_meta`` 

1774 with the model's *coerced* ``args`` (so a consumer never sees the raw,
