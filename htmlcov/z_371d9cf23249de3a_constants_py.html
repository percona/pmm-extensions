25#: Discriminator carried by an active row inside every unique index, so a retired 

26#: row (which carries its own primary key instead) never collides with its 

27#: replacement. It has to be non-NULL and outside the autoincrement range: a NULL 

28#: never compares equal to another, so a NULL sentinel would silently stop the 

29#: index constraining active rows at all. 

30ACTIVE_RETIREMENT_KEY: Final = -1

43#: Longest error text stored on an entity's ``last_sync_error``. The manager

47#: How far ahead of this service's clock a reported ``attempted_at`` may sit 

48#: before the report is refused. The ordering guards admit anything not older 

49#: than the stored attempt, so a reporter whose clock runs fast stamps a 

50#: freshness no later report can supersede until wall-clock time catches up — 

51#: and one whose clock is then corrected is locked out for the whole interval. 

52#: Refusing leaves the entity looking stale, which is the direction the rest of 

53#: this mechanism already errs in. Wide enough to absorb the drift between two 

54#: containers of one deployment without absorbing a misconfigured clock. 

55SYNC_ATTEMPT_MAX_CLOCK_SKEW: Final = timedelta(minutes=5)
