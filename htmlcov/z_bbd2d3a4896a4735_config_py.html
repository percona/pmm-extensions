31class AnonymizerSettings(BaseYamlSettings): 

32 """Define settings for task data anonymization. 

33 

34 The module-level ``anonymizer_settings`` is wrapped in an 

35 :class:`OverridableSettingsProxy`, so its underlying instance is constructed 

36 and validated lazily on first attribute access rather than at import. The 

37 Tasks Celery worker's ``start_settings_override_refresher`` handler calls 

38 ``anonymizer_settings._resolve()`` at ``worker_process_init`` so a bad 

39 config surfaces in the worker log at child start rather than mid-task -- 

40 Celery absorbs what a signal receiver raises, so the child still starts. 

41 Removing that call regresses to lazy validation. 

42 

43 :cvar SETTINGS_PREFIXES: The prefixes for anonymizer related settings in the 

44 configuration file. Set to ``["TASKS", "ANONYMIZER"]``. 

45 :param DEFAULT_ENTITIES: A mapping of task owners to sets of anonymizer entities. 

46 If set to ``"*"``, defaults to all available anonymizer entities for all owners. 

47 If a list of anonymizer entities is provided, it will be used as default for all 

48 owners. Defaults to an empty set. 

49 :param NLP_MODELS: A mapping of language codes to spaCy model names for NLP 

50 processing. Defaults to ``{"en": "en_core_web_sm"}``. 

51 """
