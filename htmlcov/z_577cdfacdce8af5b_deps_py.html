196def _declared_source_override(task: Task) -> dict[str, Any]: 

197 """Return a ``data`` override declaring the source of a stamp that describes it poorly. 

198 

199 The edit form seeds each field from the served stamp and falls back to the 

200 schema default where the stamp has no value, so a stamp written before the 

201 source controls existed would seed ``source_transport`` to ``local``. The 

202 gates then hide the SSH and object-store fields, and a hidden field is 

203 dropped from the submission entirely, so saving that form would discard 

204 credentials the restore still needs. The same holds for an AES-256 key file a 

205 stamp names without declaring the format that reveals it. Repairing the stamp 

206 here means the form opens on the source its stored values imply, keeping a key 

207 file the engine can read and dropping one it cannot. 

208 

209 Re-validating through :class:`RestoreCreate` rather than serving the repair 

210 directly keeps the served stamp exactly what a subsequent ``PUT`` would 

211 accept. It is tolerant of a stamp that cannot be validated at all, because

213 take out the whole page. 

214
