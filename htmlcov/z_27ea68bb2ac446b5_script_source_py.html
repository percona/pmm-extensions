16"""Define the ``ScriptSource`` seam for script-backed task apps. 

17 

18A script-backed task app has no single create model: each script carries its own 

19dynamically-synthesised form, and its surface is script-centric (listing, 

20per-script form schema, execute, history) rather than the model-first ``POST /`` 

21create envelope. :class:`ScriptSource` captures the hooks 

22:func:`~app.extensions.apps.framework.api.derive_script_routes` needs to derive that 

23surface, so a :class:`~app.extensions.apps.framework.apps.TaskExecutionApp` can declare 

24``script_source=`` instead of hand-wiring the routing and execution. 

25 

26The framework programs against the structural :class:`ScriptProtocol` and never 

27imports a concrete script type; the concrete type, the listing source (disk or 

28DB), the artifact-URL salt, and the execution-meta shape are all supplied by the 

29consumer. 

30"""

137@dataclass(frozen=True, slots=True) 

138class ScriptSource(Generic[S, Q]): 

139 """Carry the hooks ``derive_script_routes`` derives a script app's surface from. 

140 

141 The framework owns the contract and the route derivation; the consumer supplies 

142 the concrete script type, the listing source, the per-script form synthesis, and 

143 the execution-meta assembly (closing over its own artifact-URL salt and meta 

144 shape). ``build_execution_meta`` receives the script and the validated 

145 :class:`ScriptExecuteWrite`, so a consumer reads ``executor_host`` / ``sudo`` / 

146 ``args`` from one place. 

147 

148 :param script_dir: The directory the scripts live in (the static-mount target and 

149 the listing root the consumer's hooks close over). 

150 :param load_script: Resolve a single script by filename; raise 

151 :class:`~app.core.exceptions.HTTPNotFoundException` when it is absent. 

152 :param list_scripts: Return a page of scripts plus the filtered total. Receives 

153 the resolved list-query value of type ``Q`` (a Core 

154 :class:`~app.core.db.list_query.ListQuery` for push-down sources, an 

155 :class:`~app.core.db.in_memory_list_query.InMemoryListQuery` for in-memory 

156 sources) and the pagination window. Either argument is ``None`` when the 

157 route derives no query capability: ``(None, None)`` lists every script 

158 (non-paginated route), ``(None, pagination)`` returns the pagination slice of 

159 the full set with the full-set total (paginated, no spec), and 

160 ``(query, pagination)`` returns the filtered/sorted page with its filtered 

161 total (paginated, spec). 

162 :param load_scripts: The optional batch loader resolving several filenames in 

163 one round trip, returning a filename-keyed mapping of only the scripts it 

164 resolved (an absent key means unresolved). When ``None`` the framework's 

165 :func:`resolve_scripts` falls back to looping ``load_script`` (see there), 

166 so a source that does not opt in keeps working unchanged. 

167 :param build_form_schema: Synthesise a per-script :class:`AppSchema` from the 

168 script's frontmatter parameters. 

169 :param build_execution_meta: Assemble the execution-meta model the framework 

170 posts to the Tasks API, from the script and the validated request body. 

171 :param list_response: Project a script into its list-row response model. 

172 :param static_schema: The optional plugin-level schema served at ``GET /schema``; 

173 when ``None`` the route is not registered. 

174 :param list_response_model: The optional response model typing the derived 

175 ``GET /`` as ``list[list_response_model]``; when ``None`` the list route 

176 stays untyped (back-compatible — a source that does not opt in keeps the 

177 original untyped list). 

178 :param list_query_dep: An optional source-supplied request-boundary dependency 

179 yielding the ``Q`` handed to ``list_scripts``. Set it when the resource adds 

180 filter parameters on top of sort and search: the dependency composes the Core 

181 one (built from the app's spec) with its own ``Query`` params, so the spec 

182 stays the single authority for the sortable allowlist while the route also 

183 carries the resource's base restrictions. When ``None`` (default) the 

184 framework builds the dependency from the app's spec directly. Either way the 

185 app must declare a spec, or the derived route exposes no query at all. 

186 :param in_memory_list_query: Whether the source materializes its whole set and 

187 applies sort/search/pagination in-process (a disk-backed source) rather than 

188 pushing them down to SQL. Selects which list-query dependency the framework 

189 builds for the app's :class:`~app.core.db.list_query.ListQuerySpec` — the 

190 in-memory dep (:func:`~app.core.db.deps.make_in_memory_list_query_dep`) 

191 when ``True``, the SQL dep (:func:`~app.core.db.list_query.make_list_query_dep`) 

192 otherwise. Meaningful only on a source with no ``list_query_dep``, which 

193 supersedes it. 

194 """ 

195 

196 script_dir: Path 

197 load_script: Callable[[str], Awaitable[S]] 

198 list_scripts: Callable[ 

199 [Q | None, Pagination | None], Awaitable[tuple[Sequence[S], int]] 

200 ] 

201 build_form_schema: Callable[[S], AppSchema] 

202 build_execution_meta: Callable[[S, ScriptExecuteWrite], BaseModel] 

203 list_response: Callable[[S], BaseModel] 

204 static_schema: AppSchema | None = None 

205 list_response_model: type[BaseModel] | None = None 

206 load_scripts: Callable[[Sequence[str]], Awaitable[Mapping[str, S]]] | None = None 

207 list_query_dep: Callable[..., Q] | None = None 

208 in_memory_list_query: bool = False 

209 

210 def __post_init__(self) -> None: 

211 """Reject a source whose two list-query dependency knobs disagree. 

212 

213 The framework prefers ``list_query_dep`` when both are set, so 

214 ``in_memory_list_query`` would be dropped without a word. The spec-coupled 

215 half of this capability cannot be checked here — a source cannot see the app's 

216 spec — and lives on ``TaskExecutionApp`` instead. 

217 

218 :raises ValueError: When ``in_memory_list_query`` is set on a source that also 

219 supplies a ``list_query_dep``. 

220 """ 

221 if self.list_query_dep is not None and self.in_memory_list_query: 

222 raise ValueError( 

223 "ScriptSource: list_query_dep supersedes the framework's in-memory " 

224 "dependency; set in_memory_list_query only on a source with no " 

225 "list_query_dep" 

226 )

229def _validate_script_filename(filename: str) -> None: 

230 """Reject a ``snippet_filename`` that could resolve outside the script directory. 

231 

232 The framework cannot trust a consumer's ``load_script`` to validate the path 

233 itself (a disk-backed loader may join the raw value straight onto 

234 ``script_dir``), so reject directory traversal at the seam — mirroring the 

235 snippets plugin's path-safety guard — before any ``load_script`` lookup runs. 

236 

237 :param filename: The raw ``snippet_filename`` query value. 

238 :raises HTTPBadRequestException: When the filename uses a Windows separator, is 

239 absolute, or contains an empty / ``.`` / ``..`` path component. 

240 """ 

241 if "\\" in filename or PurePosixPath(filename).is_absolute(): 

242 raise HTTPBadRequestException(detail=f"Invalid script filename: {filename!r}") 

243 if any(part in ("", ".", "..") for part in filename.split("/")): 

244 raise HTTPBadRequestException(detail=f"Invalid script filename: {filename!r}") 

245

247def make_script_dep(source: ScriptSource[S]) -> Callable[[str], Awaitable[S]]: 

248 """Return a dependency resolving the ``snippet_filename`` query param to a script. 

249 

250 Mirrors the snippets plugin's ``SnippetDep``: the per-script routes carry the 

251 filename in a ``snippet_filename`` query parameter (never a path segment, which 

252 would shadow ``GET /`` and ``GET /schema``), and resolution delegates to 

253 ``source.load_script`` so a missing script surfaces as that loader's 404. 

254 

255 :param source: The script source whose ``load_script`` resolves the filename. 

256 :return: A FastAPI dependency returning the resolved script. 

257 """ 

258 

259 async def _get_script( 

260 snippet_filename: Annotated[ 

261 str, 

262 Query(description="Script filename (relative path under the script dir)."), 

263 ], 

264 ) -> S: 

265 _validate_script_filename(snippet_filename) 

266 return await source.load_script(snippet_filename) 

267 

268 return _get_script

271async def resolve_scripts( 

272 source: ScriptSource[S], filenames: Sequence[str] 

273) -> dict[str, S]: 

274 """Resolve several script filenames in one pass, keyed by filename. 

275 

276 The single entry point every batch caller routes through, so the seam's 

277 path-safety guard runs on every filename before any lookup regardless of 

278 whether the source opted into a batch loader. Filenames are deduplicated 

279 order-preservingly, so a repeated filename is looked up once. A source that 

280 sets ``load_scripts`` resolves the whole selection in one round trip; 

281 otherwise the framework loops ``load_script``, treating that loader's 404 as 

282 an unresolved filename rather than propagating it. 

283 

284 The result carries only the filenames that resolved, so the caller decides 

285 the failure policy: a schema route can raise its whole-request 404 for the 

286 first missing key, while an execute route can turn a missing key into a 

287 per-item error. Traversal is still fatal — an unsafe filename raises before 

288 any lookup, matching the single-script dependency. An empty selection 

289 resolves to an empty mapping without touching either loader. 

290 

291 :param source: The script source whose loader(s) resolve the filenames. 

292 :param filenames: The requested filenames, possibly with duplicates. 

293 :return: A mapping of each resolved filename to its script; unresolved 

294 filenames are absent. 

295 :raises HTTPBadRequestException: When any filename fails the traversal guard. 

296 """ 

297 unique = list(unique_everseen(filenames)) 

298 if not unique: 

299 return {} 

300 for filename in unique: 

301 _validate_script_filename(filename) 

302 if source.load_scripts is not None: 

303 return dict(await source.load_scripts(unique)) 

304 resolved: dict[str, S] = {} 

305 for filename in unique: 

306 try: 

307 resolved[filename] = await source.load_script(filename) 

308 except HTTPNotFoundException: 

309 continue 

310 return resolved
