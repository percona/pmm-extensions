48class NodeResponse(BaseSQLModel, RetiredAtBase, SyncHealthBase, NodeBase): 

49 """Represent a node API response. 

50 

51 :param id: The primary key for the table. Auto-incremented and not nullable. 

52 :param created_at: The timestamp when the record is created. Defaults to the current 

53 time in UTC. 

54 :param updated_at: The timestamp when the record is last updated. Automatically 

55 updated on changes. 

56 :param address: The network address of the node. 

57 :param name: The name of the node. 

58 :param external_id: An external identifier for the node. 

59 :param source: The source from which the node information is derived. 

60 :param type: The type of the node (e.g., remote, generic). 

61 :param retired_at: When the node stopped being reported upstream, or None while 

62 it is active. 

63 :param last_synced_at: When a syncer last confirmed the node against its 

64 source, or None if that has never happened. 

65 :param last_sync_error: The message from the most recent failed attempt, or 

66 None while the node is syncing cleanly. 

67 :param sync_failing_since: When the current run of failures began, or None 

68 while not failing. 

69 :param consecutive_failures: Failed attempts since the last success. 

70 :param newest_attempt_at: When the newest accepted attempt began, whatever 

71 its outcome, or ``None`` if none has been reported, or the upgrade 

72 time for a row that was failing when the column was added. 

73 :param services: A list of services associated with the node. 

74 """ 

75 

76 services: list["Service"]
