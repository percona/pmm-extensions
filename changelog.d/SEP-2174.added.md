The settings API now reports an override that is stored but ignored because it breaks a cross-field rule: the field carries `override_ignored_reason`, naming the rule(s), on the admin settings list and detail reads and on Operations for MongoDB's `/api/apps/om_inventory/config`. Previously the field read as overridden while its YAML, environment or default value ran. The settings UI does not display the reason yet; it is available to API clients.
