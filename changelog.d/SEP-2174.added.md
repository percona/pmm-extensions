The settings API now reports an override that is stored but ignored because it breaks a cross-field rule: the field carries `override_ignored_reason`, naming the rule(s), on the admin settings list and detail reads and on Operations for MongoDB's `/api/apps/om_inventory/config`. The field still reports `has_override: true` and its last writer, so the stored override can be reset. The settings UI does not display the reason yet; it is available to API clients.
