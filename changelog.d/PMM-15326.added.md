Added the OpenManager Inventory app, which sweeps the MongoDB estate over Nomad and serves the hosts, services and run history it collects under `/api/apps/om_inventory/`, configured through the new `EXTENSIONS.OM_INVENTORY` settings block or the app's own `/config` endpoint. The sweep is off until PMM's OpenManager switch turns it on; once on, it runs every ten minutes by default. It is activated in the shipped side-car, and the half that consumes it ships in pmm-managed, so a PMM built without `managed/services/om` reaches the endpoints with nothing reading them.
Added `DELETE /api/apps/om_inventory/hosts/{node_id}` and `DELETE /api/apps/om_inventory/services/{service_id}`, so a host or service row left behind when a node was replaced or re-registered under a new id can be cleared without waiting for the freshness columns to age it out on their own.
Added `DatabaseOptions.SCHEMA_TRANSLATE_MAP`, applied once on engine creation so every caller sharing a `DatabaseOptions` gets the same schema remapping without composing its own. Built for `om_inventory`'s `om` schema, which SQLite cannot create for real and which the PostgreSQL test lane routes per xdist worker, but available to any app whose tables need a non-default schema.
Added `GET /api/tasks/hosts/states/`, which reports every executor host the backend knows about, not only the ones a job could be placed on, with `reachable` and `driver_healthy` given separately so a caller can tell a never-onboarded host apart from one that is down or has a broken driver.
