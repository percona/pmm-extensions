A failed my.cnf or TLS certs copy after a successful localhost XtraBackup is logged as a warning, no longer aborts the run before post-run encryption or upload, and finishes the run as a warning rather than OK so operators can see the missing artifacts. Zero-size backups already finished as a warning; they now also keep that warning on the Prometheus status metric (instead of being overwritten to OK) and report local_path / size_mb like other warning outcomes.
