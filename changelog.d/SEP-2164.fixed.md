A failed my.cnf or TLS certs copy after a successful localhost XtraBackup is logged as a warning, no longer aborts the run before post-run encryption or upload, and finishes the run as a warning rather than OK so operators can see the missing artifacts. Warning runs, zero-size backups included, now also report local_path and size_mb. The Prometheus backup status metric still records these runs as passed, so the backup report does not list them as failed.
