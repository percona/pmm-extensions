A running task whose Celery sync fails, for example while Nomad is unreachable, now releases its sync lock, so the next sweep retries it instead of waiting for SYNC_LOCK_TTL to expire. The sweep also dispatches each run as its own Celery task, so one failed sync no longer holds back the other runs claimed in the same sweep. A sync that starts only after its lock expired and another syncer took it over now skips the run instead of syncing it twice. The manual sync endpoint now releases its lock only when the sync fails before the status is saved, and leaves alone a lock another syncer took in the meantime.
