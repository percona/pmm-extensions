Added the Operations Bootstrap app, which provisions a one-member or three-member MongoDB replica set from Percona's packages on Ubuntu or Rocky Linux hosts, step by step over Nomad with rollback, and serves those runs under `/api/apps/om_bootstrap/` for pmm-managed to drive, activated in the shipped side-car. A run enables MongoDB authorization in a finalize phase once the first user exists, can be aborted in flight through `POST /runs/{id}:cancel`, and takes per-run data/log paths, port and bind IP plus per-member replica-set election settings (priority/votes/hidden/delay).
