Under the MongoDB root of the Support diagnostics category browser, the PBM diagnostics script now lists under Backup / PBM, and the replication lag check and the replica set collection script list under Replica Set Replication; the collection script keeps its existing crash and performance categories. Existing installations re-file the scripts on the next snippet sync (at startup or on the sync interval), and the edited scripts are re-approved only while `EXTENSIONS.SNIPPETS.AUTO_APPROVE_BUILTIN_SNIPPETS` is on: with it off they lose approval and leave the browser and search until an administrator approves them again, and a script an administrator had revoked stays revoked.
