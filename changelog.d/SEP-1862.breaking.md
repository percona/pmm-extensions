The inventory browser page is removed with no replacement UI, and with it five read routes under /api/apps/inventory/: GET /{entity}/, GET /{entity}/{item_id}, GET /nodes/{node_id}/system-observation, GET /services/{service_id}/system-observation and GET /schema. Those paths are no longer registered, so every verb on them answers 404. Read the catalog from the inventory service's own routes under /api/inventory/, which are unchanged; API clients must regenerate @pmm-extensions/api. Sync, sync status, syncer discovery and connectivity checks under /api/apps/inventory/ are unaffected.
