The ProxySQL status report no longer reads a notice the mysql client prints on a successful call as table names to dump, and no longer leaves out the host priority file because of one. A percent sign in the report — in a dumped value, a table name or the client's error, such as the `'admin'@'%'` of an access-denied message — now prints once instead of doubled. On Linux, `--table <name>` now filters the dump instead of stopping with "--table requires an argument". The fix reaches an installation on the first snippet sync after upgrade: the updated built-in script is re-approved automatically only when built-in auto-approval is on and an administrator has not revoked its approval; otherwise an administrator must approve it before it runs.
