A MySQL backup on a host whose Nomad data directory is on a disk more than 80% full now records its location and size, so the Restore form lists it. PMM Extensions used to read the result of a run after it had released the working directory of the run, and such a host deletes that directory at once; it now reads the result first. This holds when PMM Extensions learns that the run ended while it still holds that directory, which is 90 seconds by default; a run it learns of later can still be recorded without them. Records written before the upgrade keep their empty fields; type the path of the backup in the Restore form for those.
