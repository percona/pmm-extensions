New AUTH__PROVIDER__GRAFANA__EXCHANGE_TOKEN_MAX_AGE (default 5 minutes; must be positive, rejected at startup otherwise) sets how long a session-exchange bearer stays valid. It does not fall back to the access-token lifetime, because the documented sign-out and role-change bound derives from it. Note that EXTENSIONS__AMBIENT_SESSION_SSO_ENABLED now gates embedded-UI authentication as well as standalone SPA auto-login, so turning it off in a PMM-embedded deployment signs the embedded UI out.
