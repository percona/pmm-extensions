The ProxySQL status report no longer prints credentials from its admin config file. The value of any setting whose name contains PASS, PWD, SECRET, TOKEN, KEY, AUTH or CRED, or whose value is a URL with a password, shows as `[REDACTED]`, including commented-out settings; an empty value still shows, without its trailing comment. A line that is not a plain `KEY=value` assignment, a line continuing a value from the line above, and a comment that names a credential are replaced by `# [REDACTED: line not shown]`, since they could hold a secret the masking cannot find. Other settings, blank lines and other comments still show as written. The fix reaches an installation on the first snippet sync after upgrade: the updated built-in script is re-approved automatically only when built-in auto-approval is on and an administrator has not revoked its approval; otherwise an administrator must approve it before it runs.
