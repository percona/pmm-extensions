The MySQL Restores form now says that an XtraBackup restore stops MySQL on the execution host, which command it runs to do so, and that MySQL stays stopped if the restore fails after the stop. It also says what **Port** is used for: the restore connects to that port to check that MySQL stopped and started, so it must be the port of the server the init command controls. An XtraBackup restore also prints a line every minute while it waits for MySQL to stop; that wait used to print nothing for up to ten minutes. The form text changes with the upgrade; the new line appears from the next run of a restore task.
