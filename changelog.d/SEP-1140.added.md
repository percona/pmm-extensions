MySQL Topology app: a standalone, opt-in plugin (enable via `EXTENSIONS.APPS`) that renders an interactive React Flow graph of MySQL replication, dual-primary pairs, and Percona XtraDB Cluster groups, collected on demand by sharded `run-python` tasks dispatched to executor hosts and polled by the UI until every shard finishes. It sources its MySQL host list from Inventory. Replaces the manual `db_tree.py` text-tree workflow with a cached, refreshable visualization that reuses the same `~/.my.cnf` / `~/.mylogin.cnf` credential lookup as `MySQLSyncer`.
