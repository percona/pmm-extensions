Casdoor and Grafana sign-in traffic, PMM alert contact-point calls and PagerDuty alert events no longer write tokens, client secrets, user records, integration keys or routing keys into the application log. Their log lines still name the method, path and status. Setting `AUTH__PROVIDER__CASDOOR__WITHHOLD_BODY_LOG` or `AUTH__PROVIDER__GRAFANA__WITHHOLD_BODY_LOG` to `false` now fails at startup instead of logging those bodies.
