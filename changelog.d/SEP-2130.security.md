Saving a credential-bearing endpoint URL in the settings admin (`NOMAD__endpoint`, `PMM__endpoint`, `INVENTORY_ENDPOINT`, `TASKS_ENDPOINT`) no longer leaves the typed password on screen until the page is reloaded: after a successful save the edit field shows the URL with its password masked, the same value as *Current*. A save that fails still keeps the typed URL in the field so it can be corrected, and saving the masked URL back keeps the stored password.
