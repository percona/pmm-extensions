Operations installs MongoDB only onto OS releases Percona supports for the chosen version: MongoDB 7.0 onto Ubuntu 22.04 and 24.04 and Rocky Linux 8 and 9, and MongoDB 8.0 onto those and Rocky Linux 10. An install onto any other release, such as Ubuntu 20.04, now fails its pre-check before anything on the node changes, instead of installing an old build Percona no longer supports or failing at the repository step. A run asking for a version no release is supported for, such as 9.0, is refused when it is created. PMM reads the supported releases from the new `GET /api/apps/om_bootstrap/supported-releases`.
