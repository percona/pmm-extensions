JSON REST API for MongoDB PBM backups and restores under `/api/plugins/backup_mongo/` and `/api/plugins/backup_mongo/restores/` (list, create, detail, execute, delete for parent task groups plus derived/child tasks), a schema-driven React UI at `/backups/mongodb`, and `GET /api/extensions/task-history/` to merge execution history across task-group siblings without browser access to the Tasks sub-app.
