A per-service `{EXTENSIONS,INVENTORY,TASKS}__*` settings name now deterministically overrides the unprefixed global spelling of the same destination within a given source (environment, dotenv, or secrets directory); cross-source ranking is unchanged, and deployments that set only one spelling are unaffected. The PMM side-car mount recipe is now one `DATABASE__PASSWORD` file instead of three identical per-service password files — see `sidecar/README.md` for the full recipe.
