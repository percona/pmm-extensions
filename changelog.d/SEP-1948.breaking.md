Three more inventory writes under `/api/inventory/` are now restricted to the internal service principal and answer 403 for an **admin** user token: `PUT /nodes/{id}/system-observation`, `PUT /services/{id}/system-observation` and `POST /services/{id}/schemas/`. Only the syncers, which authenticate with `EXTENSIONS_INTERNAL_TOKEN`, write through them, so syncer writes are unaffected. Any write route added to the node or service API later is syncer-only unless it is explicitly exempted; the node and service identity-link decisions stay the only exemptions and keep their current access.
