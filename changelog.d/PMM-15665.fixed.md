A failed Operations install step now says why it failed, from the node's own output, instead of "Task history N ended failed"; the pre-check also refuses a node whose port is already taken or that has a `mongod` outside `sudo`'s `PATH` (such as `/usr/local/bin`), and a `mongod` that does not come up reports its journal and log errors. A failed pre-check is no longer retried, a host the install never reached is rolled back as skipped rather than reported as torn down, low free space is reported in GiB with the directory measured, and the scan now measures free space at the data directory the install uses, so the two agree.
