Operations Inventory scans no longer read the node-side `~/.mongodb_uri` credential file. The on-host probe collects OS, process and unauthenticated database facts only, and reads a config server's role from `sharding.clusterRole` in the mongod config file rather than by logging in; PMM resolves the authenticated cluster role from the MongoDB exporter's metrics. A scan no longer requires a standing plaintext MongoDB credential on each monitored host.
