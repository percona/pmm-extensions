Runtime app enable/disable: an admin REST API (`GET` and `PUT /api/admin/apps/`) toggles each app's state, a public `GET /api/apps/` exposes it to the navigation, and a per-router guard returns HTTP 503 for disabled apps without a restart. Disabled apps are hidden from the sidebar and the React shell navigation. Add `ENABLED: false` to an `EXTENSIONS.PLUGINS` entry to ship a plugin disabled; Inventory is always enabled.
