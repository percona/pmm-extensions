Viewers of the same running task now share one Nomad log connection per step and log type in each Tasks process, so `log_stream_max_connections` bounds how many runs are being watched rather than how many people watch them. Live-log offsets are now the byte position each viewer has received, counted in Nomad's cumulative request-offset space, rather than the offset Nomad reports on each frame, so a viewer can resume from any offset it was sent, including after Nomad merges or splits frames or rotates a step's log file.
