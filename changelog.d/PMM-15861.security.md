`EXTENSIONS_INTERNAL_TOKEN` no longer passes the role check on every write. It is admitted only on the writes made with no user behind them, by the inventory sync, the Operations scan, ATW, the log stream, and PMM Server's bootstrap stepper and Operations switch. On any other write it is ranked as a viewer, so a leaked token can no longer delete Operations hosts or services, create a bootstrap run, decide inventory identity links, delete task definitions or manage periodic tasks. It keeps the task-running rights those callers need, so it must still be protected as a privileged credential.
