OpenAPI specs now expose populated `info.title`, `info.version`, and `info.description`, and use tag-prefixed `operationId` values (e.g. `extensions_list_things_things_get`) for stable codegen across similarly named handlers. Each mounted sub-app publishes its own document: `/openapi.json` (core: OAuth/users), `/api/inventory/openapi.json`, `/api/tasks/openapi.json`, and the PMM Extensions web app at `/api/extensions/openapi.json`.
