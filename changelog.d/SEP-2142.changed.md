The side-car image now runs Python 3.14 instead of 3.11; the change reaches an installation when its side-car image is upgraded. Executor hosts are unaffected: the Python scripts the side-car sends to them still run on Python 3.9 and later. One dispatch detail changes with it: a task whose inline Python payload has a quoted value inside an f-string replacement field, such as f"{os.getenv('HOME')}", is now sent unminified, because minifying it on 3.14 could produce code older host interpreters cannot parse. Such a payload is larger on the wire, and one that only fitted Nomad's 16 KiB dispatch payload limit once minified is now refused by Nomad at dispatch. Payloads PMM Extensions ships are unaffected and are still minified.
