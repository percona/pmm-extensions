The Support diagnostics category browser now offers a Replica Set Replication leaf under Replication High / Availability and a new Backup and Recovery parent with a Backup / PBM leaf. Under the MongoDB root, the PBM diagnostics script lists under Backup / PBM, and the replication lag check and the replica set collection script list under Replica Set Replication; the collection script keeps its existing crash and performance categories. Existing installations re-file the scripts on the next snippet sync (at startup or on the sync interval), and the edited scripts are re-approved only while `EXTENSIONS.SNIPPETS.AUTO_APPROVE_BUILTIN_SNIPPETS` is on: with it off they lose approval and leave the browser and search until an administrator approves them again, and a script an administrator had revoked stays revoked.
