The PMM-embedded side-car reads mounted secret files: settings-env.sh consults SECRETS_DIR for SECRET_KEY and every canonical name it derives, leaving a mounted name unexported so the settings classes resolve it from the file. A file supplies only the name it is named for, so keeping the database password out of the environment means mounting all three {EXTENSIONS,INVENTORY,TASKS}__DATABASE__PASSWORD files; see sidecar/README.md for the full mount recipe.
