An Operations MongoDB install on an Ubuntu node no longer leaves the downloaded packages behind. The Percona Server for MongoDB .debs and their dependencies used to stay in `/var/cache/apt/archives/`, after a successful install and after a rollback alike, and `percona-release`'s .deb stayed in `/tmp`. apt now downloads them into a directory of the install's own, `/var/cache/om-bootstrap`, which the install deletes once it succeeds and the rollback deletes after a failure, and the .debs already in apt's own cache are left alone. The repository step removes `percona-release`'s .deb whether it succeeds, fails or times out.
