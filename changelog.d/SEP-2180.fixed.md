XtraBackup restores now apply the incremental chain: S3 (s3cmd and awscli) and GCS sources no longer restore only the full backup, local and SSH sources no longer fail with a TypeError when incrementals exist, and picking an incremental run as the source restores the full backup plus the chain up to that run. Every backup in the chain is checked before MySQL is stopped, and a chain that cannot be listed now fails the restore instead of restoring the full backup alone. SSH sources list the chain with non-interactive sudo, which the restore copy already requires.
