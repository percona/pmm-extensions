Add POST /api/oauth/session/exchange, which exchanges an ambient PMM/Grafana session cookie for a short-lived PMM Extensions bearer token so an embedded UI authenticates as the real signed-in user instead of a shared deployment credential. No cookie is set and no refresh token is issued; the token lifetime is AUTH__PROVIDER__GRAFANA__EXCHANGE_TOKEN_MAX_AGE (default 5 minutes), which also bounds how long a signed-out browser keeps embedded access and how long a Grafana role change takes to apply. Requires EXTENSIONS__AMBIENT_SESSION_SSO_ENABLED=true.
