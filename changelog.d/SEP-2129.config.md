Add tasks setting `INVENTORY_SYNC_FOLLOWER_MAX_WAIT` (default `1 days`): the longest an `INVENTORY_SYNC_SCHEDULES` entry, such as the daily host-facts schedule, waits for the pinned `INVENTORY_SYNC_SYNCER` default's first completed inventory sync, counted from when the entry's schedule was first seeded. Once it has passed, the entry runs on its own interval even if the default never completes, for example behind an unreachable PMM, an `INVENTORY_SYNC_SYNCER` that matches no configured syncer, or a disabled default schedule. While it waits, each skipped run's task log states when the wait ends.
