`EXTENSIONS_ENCRYPTION_PROBE_TIMEOUT` is no longer read. A sidecar that has to mint its `ENCRYPTION_KEY` waits until the service databases answer, so a deployment that set the variable to bound that wait now waits past the value. Such a deployment gets one `[encryption-key]` log line saying so at each start that mints, until the variable is removed. A start waiting on a second sidecar that holds the lock on a shared state volume refuses after 120 seconds, the bound the variable's default gave it.
