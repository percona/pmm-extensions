The Operations Inventory app no longer serves `PATCH /api/apps/om_inventory/config` or `DELETE /api/apps/om_inventory/config/{key}`: an admin changes its settings through `/api/extensions/admin/settings/OmInventorySettings`, and PMM sets `ENABLED` through the new `PUT /api/apps/om_inventory/enabled`, which only PMM's service token may call. `GET /api/apps/om_inventory/config` is unchanged. A PMM Server that still calls the removed routes cannot switch Operations for MongoDB on or off, or change its settings, until it is upgraded to a release that uses the new ones.
Starting an Operations Inventory scan through `POST /api/apps/om_inventory/runs` now requires an admin; an editor gets 403.
