Removed `GET /api/users/` and `GET /api/users/{username}` from the main API; no PMM Extensions or PMM client called them, and a request to either now gets `404 Not Found`. `GET /api/users/me` is unchanged. An out-of-tree auth provider selected with `AUTH__PROVIDER__CUSTOM__PROVIDER_CLASS` no longer has to implement `get_user`; one that still defines it keeps working.
