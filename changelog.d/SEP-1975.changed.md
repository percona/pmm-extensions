The PMM side-car now mints an ENCRYPTION_KEY when neither an environment variable nor a SECRETS_DIR file supplies one, persisting it under the state directory; mount a volume at /home/extensions/state so it survives a container recreate. Minting is refused, and the container stops, when any of the three service databases already holds encrypted override values or cannot be reached, because a newly minted key could not decrypt them. A minted key is exported into every supervised program's environment, where a key mounted under SECRETS_DIR deliberately is not; mount one instead of letting it be minted if that difference matters to you.
